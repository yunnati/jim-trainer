# AI-Based Yoga Posture Correction System

## Description
This project uses a camera to detect human posture in real time.
It checks whether yoga hand posture is correct by comparing joint angles
and shows a ghost reference pose with low opacity.

## Technologies Used
- Python
- OpenCV
- MediaPipe Pose Estimation

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the project:
   python main.py

3. Press ESC to exit.

## Features
- Real-time pose detection
- Ghost posture overlay
- Correct / Incorrect posture feedback
- No wearable sensors required
